# My Expenses — Project Specification

## Project Overview

Personal finance tracker for a single user managing income (salary + extra), recurring fixed expenses, one-off purchases, and credit card charges. Tracks money across multiple wallet accounts with monthly cashflow summaries, category breakdowns, 6-month history chart, and calendar view with income/expense dots. Built as a private, self-hosted web app.

---

## Tech Stack

- **Framework:** React 18 + Vite 5
- **Language:** TypeScript (relaxed — no strict mode)
- **Styling:** Tailwind CSS 3 + custom CSS variables (surface, success, destructive color tokens)
- **Components:** shadcn/ui (Radix-based primitives, ~40 components)
- **State:** Local React state + TanStack Query v5 (wraps Supabase)
- **Backend/Auth:** Supabase (Postgres + Auth, anon key embedded, no RLS enforced)
- **Charts:** Recharts
- **Forms:** react-hook-form + Zod resolvers
- **Notifications:** Sonner toasts
- **Icons:** Lucide React
- **Date utils:** date-fns
- **Testing:** Vitest + Testing Library
- **Linting:** ESLint flat config
- **Package manager:** Bun (bun.lockb)

## Core Features

1. **Dashboard** — Income vs spent vs committed vs available balance; wallet snapshot; expenses-by-category pie chart; 6-month bar chart (single query); Monthly Statement tab with export to XLSX.
2. **Overview Calendar** — Large month calendar showing income dots (green) and expense dots (red) per day; click day for detail dialog.
3. **Expense CRUD** — Record one-off purchases, toggle paid/unpaid via expense_payments, assign category + wallet.
4. **Fixed Expense Templates** — Recurring monthly bills with start_date/end_date; paid/unpaid per month via fixed_expense_payments; edit modal for amount and dates.
5. **Card Charges** — Three types: one-time (fires once), installment (N months), recurring (every month until deactivated). Toggle active/inactive.
6. **Card Payments** — Pay card charges from a wallet; payment history per card; paid/unpaid sync.
7. **Salary Entry** — One record per month, assigned to a wallet. Replaces previous entry for same month on re-save.
8. **Extra Income** — Non-salary earnings (modal dialog), assigned to a wallet.
9. **Wallet Accounts** — Named accounts with color; transfer between accounts via modal; balance computed from payments.
10. **Tables (CRUD)** — Manage categories, credit cards, wallet accounts in-place.
11. **Dark/Light Theme** — Toggle via next-themes.
12. **Month Selector** — Global month context used across all pages.

## Conventions & Patterns

- **Path alias:** `@/*` maps to `./src/*`.
- **Money:** Stored as floats, formatted with `Intl.NumberFormat`. All date logic uses UTC.
- **Month key:** `yyyy-MM-01` (UTC). Fixed expenses filter by `start_date <= last day of month AND (end_date IS NULL OR end_date >= first day of month)`.
- **State:** No global store; each page owns its local state. TanStack Query used only for QueryClient boilerplate.
- **Supabase pattern:** Direct `supabase.from(table)` calls without custom hooks. New tables queried with `as any` due to missing Supabase types.
- **Tables.tsx** — Single component handles 3 tabs (categories/cards/wallets) via `useState<Tab>`.
- **Paid status pattern:** Check payment table existence (expense_payments, fixed_expense_payments, card_payments) instead of boolean on main table.
- **Fixed expense amount priority:** `payment.amount ?? fixed_expense.amount`.
- **Wallet balance:** Computed on-the-fly from salary + extra + distributions + transfers in − paid expenses/fixed/card payments.
- **Dialog forms:** MySalary, ExtraIncome, MyWallet transfer, FixedExpenses edit all use shadcn Dialog.
- **ESLint:** Relaxed TS config (`noUnusedLocals: false`, `strict: false`).
- **CSS classes:** Custom tokens via `hsl(var(--...))`. Custom tokens: `surface`, `success` (green), `label-mono` (Geist Mono, uppercase).
- **Component names:** `PascalCase` for React components, `camelCase` for functions/hooks. Pages default-exported; components named-exported.
